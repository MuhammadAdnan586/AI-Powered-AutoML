\# Module 2 – AutoML Engine



AutoML Engine automatically trains aur benchmark karta hai multiple machine 

learning models ek dataset par, taake best-performing model dhoonda ja sake.



\## Supported Models



Ye platform training ke dauran ye 7 models automatically train karta hai:



1\. Random Forest

2\. Gradient Boosting

3\. Logistic Regression

4\. Support Vector Machine (SVM)

5\. K-Nearest Neighbors (KNN)

6\. Decision Tree

7\. Naive Bayes



\## Benchmarking



Har model train hone ke baad, uska accuracy score calculate hota hai aur 

"Score Distribution" leaderboard mein rank ke sath dikhaya jata hai — 

taake user sabse best model easily identify kar sake.



Example ranking (dataset-dependent, actual scores har dataset ke sath 

badal sakte hain):



| Rank | Model | Accuracy |

|---|---|---|

| 1st | Random Forest | 83.80% |

| 2nd | Gradient Boosting | 82.12% |

| 3rd | Logistic Regression | 81.56% |

| 4th | SVM | 81.56% |

| 5th | K-Nearest Neighbors | 81.01% |

| 6th | Decision Tree | 77.09% |

| 7th | Naive Bayes | 77.09% |
